# Foundly

Foundly помогает университетскому сообществу находить потерянные вещи и
возвращать найденные владельцам.

## Запуск

```bash
npm ci
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000). Для production-сборки
используйте `npm run build`, для проверки стиля — `npm run lint`.

## Демо-режим

Пока в проекте нет серверной базы данных и авторизации. Новые объявления
сохраняются в `localStorage` текущего браузера, отображаются в общей ленте этого
браузера и открываются по ссылке `/item/[id]`. Данные не отправляются на сервер,
не синхронизируются между устройствами и могут быть удалены при очистке данных
браузера. Telegram-контакт будет публичным, если объявление когда-либо будет
опубликовано на сервере.

Фотографии принимаются в формате JPG, PNG или WebP размером до 5 МБ. Поскольку
браузер ограничивает объём `localStorage`, для крупных фотографий может
потребоваться освободить место в хранилище.
