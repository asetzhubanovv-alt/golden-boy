# Foundly

Сервис объявлений о потерянных и найденных вещах в университетском кампусе.
Требования проекта описаны в [TZ.md](./TZ.md).

## Запуск

```bash
npm ci
npm run dev
```

Открой [http://localhost:3000](http://localhost:3000).

## Страницы MVP

- `/` — лента с поиском и фильтрами.
- Интерфейс доступен на казахском, русском и английском языках.
- `/add` — форма создания объявления с проверкой полей и фото.
- `/item/[id]` — подробности, Telegram-контакт, статус, удаление и жалоба.
- `/register` и `/login` — демо-регистрация и вход.

## Демо-режим

Серверной авторизации и подключения Supabase пока нет. Демо-аккаунты,
объявления, статусы и жалобы сохраняются в `localStorage` текущего браузера и
не отправляются на сервер. Пароли в демо-режиме хешируются перед сохранением,
но это не делает клиентскую авторизацию безопасной: не используй реальные
пароли и не считай проверки владельца защитой данных. На главной также есть
демонстрационные объявления.
